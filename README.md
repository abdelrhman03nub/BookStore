# 📚 BookStore MVC Application

A full-featured web application for managing books and authors built using **ASP.NET Core MVC** and **Entity Framework Core**. This project demonstrates traditional MVC architecture, database relational mapping, data validation, and clean CRUD operations.

---

## ✨ Features

- 📖 **Book & Author Management:** Full CRUD operations (Create, Read, Update, Delete) for managing books and authors.
- 🔗 **Entity Relationships:** Configured one-to-many relationships between authors and books using EF Core navigation properties.
- 🛡️ **Data Validation:** Client-side and server-side validation enforced via Data Annotations on models.
- 🔍 **Database Queries:** Optimized data retrieval and filtering using LINQ queries.
- 💾 **Database Integration:** SQL Server integration with EF Core Code-First approach and database migrations.

---

## 🛠️ Tech Stack

* **Framework:** ASP.NET Core MVC
* **Language:** C#
* **ORM:** Entity Framework Core
* **Database:** SQL Server
* **Frontend:** Razor Views, HTML5, CSS3, Bootstrap
